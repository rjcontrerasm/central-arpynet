# 2.26.1 — FRONT consistency implementation

Esta rama convierte las superficies operativas existentes en el lugar principal de trabajo y reduce Filament a administración avanzada.

## Estado final de implementación

1. **Clientes FRONT — completado.** Listado, búsqueda, alta y edición sin salir de CENTRAL, con aislamiento por organización y `viewer` en solo lectura.
2. **Mi día — completado.** Los accesos operativos a tareas, recurrencias, servicios, vencimientos e incidentes usan rutas FRONT. Ya no quedan enlaces `/admin/...` en `daily-ops.blade.php`.
3. **Proyectos FRONT — completado.** Alta, edición, participantes, permisos y acciones operativas preservando el aislamiento por organización.
4. **Servicios FRONT — completado.** Alta y edición de datos operativos/financieros, manteniendo el pipeline y los editores rápidos existentes.
5. **Obligaciones recurrentes FRONT — completado.** Directorio, alta y edición sobre el generador existente de ocurrencias.
6. **Recurrencias de tareas FRONT — completado.** Directorio, alta y edición; el listado carga responsable, organización y proyecto de forma anticipada para evitar N+1.
7. **Guardia de navegación — completado.** `FrontNavigationGuardTest` impide reintroducir enlaces `/admin/...` en las superficies operativas cubiertas y conserva como única entrada explícita a Filament el enlace raíz `Administración avanzada → /admin`.

## Seguridad y arquitectura

- No se agregan migraciones en este milestone.
- Las entidades existentes no pueden moverse entre organizaciones desde las superficies FRONT.
- `viewer` conserva acceso de lectura y no recibe controles de escritura.
- Las mutaciones operativas exigen una organización escribible, no solo membresía activa.
- Filament queda reservado para administración avanzada; la operación diaria se mantiene en FRONT.
- El despliegue a producción queda fuera de este PR y requiere un gate separado después del merge y CI verde de `main`.

## Gate de cierre

Antes del merge, el PR debe cumplir simultáneamente:

- sintaxis PHP verde;
- `FrontNavigationGuardTest` verde;
- suites específicas de Clientes, Proyectos, Servicios, Obligaciones y Tareas recurrentes verdes;
- suite completa de Central CI verde;
- PR revisado sin archivos temporales ni workflows one-shot en el diff final.
